## Changes

- Add mouse controls: left-click to sweep, right-click to flag, click an opened number to chord, and click a clipped board edge to scroll. The end-of-game buttons are clickable too.
- Make no-guess generation the default. Both generation modes preserve the exact mine count and protect the first cell and its neighbors, so the first clue is zero. Use `--mode=random` for ordinary random boards.
- Extend the solver with constraint backtracking when direct and subset deductions stall. It uses visible clues and the total mine count, and proves a cell only when the opposite assumption has no compatible layout.
- Repair stalled boards by moving mines and progressively redrawing placements. Every candidate is verified again from the first opening before it can be returned as a no-guess board.
- Add a configurable generation deadline with `--generation-timeout MILLISECONDS`, defaulting to 3000 ms. Generation has no attempt-count limit. Dense boards can time out; interactive play supports retry, cancellation and quitting, and no unchecked board is returned on timeout.
- Add `--show` for plain-text board output, `--first ROW,COLUMN` for the first opening or initial cursor, and `--seed` for reproducible generation on the same platform. No-guess reproduction also depends on the generation deadline.
- Expand regression coverage for the solver, board generation, mouse input and terminal behavior.

## 改动点

- 支持鼠标操作：左键扫雷、右键插旗，点击已打开的数字可批量扫开邻格，点击被裁切的棋盘边框可滚动视图。游戏结束后也可点击按钮重新开始或退出。
- 默认生成无猜棋盘。两种生成模式都保留指定雷数，首击及周围格子保证安全，首击数字为零。普通随机模式可通过 `--mode=random` 启用。
- 推理规则无法继续时，使用约束回溯搜索。求解器只使用已公开的数字和总雷数，只有证明相反假设不可能成立，才会确定某格安全或有雷。
- 推理卡住时，通过移雷修盘和逐步重抽雷位继续寻找棋盘；每个候选盘都会从首击重新验收，通过后才作为无猜棋盘返回。
- 可用 `--generation-timeout 毫秒数` 设置生成时限，默认 3000 毫秒，不限制尝试次数。高密度棋盘可能超时，交互模式支持重试、取消和退出；超时不会返回未通过验收的棋盘。
- 新增 `--show`，可直接输出纯文本棋盘；`--first 行,列` 可指定首击位置或初始光标，`--seed` 可在同一平台上复现生成过程。无猜模式的复现还受生成时限影响。
- 补充求解器、棋盘生成、鼠标输入和终端行为的回归测试。

## Compatibility / 兼容性

The default mode changes from random to no-guess. Explicitly pass `--mode=random` to keep ordinary random generation. Both modes now require enough safe cells for the first-click neighborhood and reject unsupported mine counts. The shared random generator also changes layouts produced by seeds from earlier versions.

默认模式从普通随机改为无猜，需要普通随机棋盘时请显式传入 `--mode=random`。两种模式都需要为首击邻域预留足够的安全格，不支持的雷数会被拒绝。由于统一了随机生成器，旧版本的种子会产生不同的布局。

## Examples / 使用示例

```sh
./minesweeper 20 20 100
./minesweeper 20 20 200 --generation-timeout 10000
./minesweeper 20 20 120 --mode=random --show --first 11,11 --seed 1
```
